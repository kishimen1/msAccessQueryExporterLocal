# Access クエリエクスポーター

> Microsoft Access データベースのクエリ・テーブル・リレーションシップをブラウザでインタラクティブに閲覧できる Windows ユーティリティ

サーバー不要・インストール不要。3 ファイルを同じフォルダに置くだけで動作します。

---

## 主な機能

- **クエリ一覧表示**: 全クエリを種別バッジ付きで表示。整形済み SQL と自動生成された日本語解説を確認できる
- **テーブル/リレーション閲覧**: テーブル構造（フィールド一覧）とテーブル間の結合関係を表示
- **検索・絞り込み**: クエリ名または SQL 内容でリアルタイム検索。種別（選択/更新/削除/追加/クロス集計/ユニオン）でフィルタリング
- **SQL 自動フォーマット**: SELECT / FROM / WHERE / JOIN などのキーワードで改行・インデントして見やすく表示
- **クロスナビゲーション**: クエリ解説内のテーブル名をクリックするとテーブルタブへ移動。テーブルカードの関連クエリリンクをクリックするとクエリタブへ移動
- **一括ダウンロード**: テーブル・リレーション・クエリの全データをテキストファイルで保存
- **ダーク/ライトテーマ**: テーマ設定はブラウザに自動保存

---

## 動作環境

| 要件 | 詳細 |
|------|------|
| OS | Windows（macOS / Linux 非対応） |
| Access エンジン | Microsoft Access インストール済み、または [Access Database Engine 2016](https://www.microsoft.com/ja-jp/download/details.aspx?id=54920) インストール済み |
| ブラウザ | Chrome / Firefox / Edge / Safari（モダンブラウザ） |

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `AccessQueryExporter.bat` | エントリーポイント。ファイルダイアログ表示・VBS 呼び出し・ブラウザ起動 |
| `ExtractToJSON.vbs` | DAO を使って Access DB を読み取り、JSON とテキストを出力 |
| `viewer.html` | 抽出結果を表示するオフライン SPA |

**3 ファイルはすべて同じフォルダに配置してください。**

---

## 使い方

### 方法 1: ダブルクリックで起動

1. `AccessQueryExporter.bat` をダブルクリック
2. ファイル選択ダイアログが開く
3. 対象の `.accdb` または `.mdb` ファイルを選択して「開く」
4. データ抽出が完了するとブラウザが自動で開く

### 方法 2: ドラッグ & ドロップ

1. エクスプローラーで `.accdb` または `.mdb` ファイルを選択
2. `AccessQueryExporter.bat` のアイコンにドロップ
3. ダイアログなしで即座に抽出が始まり、完了後ブラウザが開く

### コマンドラインから実行（上級者向け）

```bat
AccessQueryExporter.bat "C:\path\to\database.accdb"
```

## 出力ファイル

両ファイルとも `AccessQueryExporter.bat` と**同じフォルダ**に生成されます（データベースファイルの場所ではありません）。

| ファイル名 | 内容 |
|-----------|------|
| `{DB名}_result.json` | ビューア用の構造化データ（UTF-8） |
| `{DB名}_クエリ一覧.txt` | 人間が読みやすいテキスト形式のレポート（UTF-8） |

---

## ビューア（viewer.html）の機能詳細

バッチ実行後にブラウザへ自動で開きます。`viewer.html` を直接ブラウザで開いて `_result.json` を手動で読み込むことも可能です（ドラッグ & ドロップまたはクリックで選択）。

### タブ

#### クエリ / SQL タブ
- 全クエリをカード形式で表示
- 各カードに: クエリ名・種別バッジ・整形済み SQL・📋 SQL コピーボタン・日本語自動解説

**クエリ解説の内容例（選択クエリ）:**
取得フィールド・使用テーブル・JOIN 種別と条件・WHERE 条件・GROUP BY・ORDER BY などを箇条書きで表示。削除クエリには WHERE 条件がない場合に警告を表示。

#### テーブル タブ
- テーブル名・全フィールド名・そのテーブルを使用している関連クエリへのリンク

#### リレーション タブ
- テーブル間の外部キー関係を `テーブルA → テーブルB (フィールドA = フィールドB)` 形式で表示

### 検索・絞り込み
- キーワード検索: クエリ名と SQL 内容を対象にリアルタイム絞り込み
- 種別フィルター: 現在のデータに存在する種別のみボタンが表示される

### その他機能

| 機能 | 操作方法 |
|------|---------|
| SQL コピー | 各クエリカード右上の 📋 ボタン → ✅ に変化しトースト通知 |
| 一括ダウンロード | 画面右上「📥 一括ダウンロード」→ `{DB名}_クエリ一覧.txt` |
| テーマ切替 | 画面右上 🌙 / ☀️ ボタン（設定はブラウザに保存） |
| リセット | 画面右上「🔄 リセット」→ ファイル選択画面に戻る |

## トラブルシューティング

### `対応していないファイル形式です`
- **原因**: `.accdb` / `.mdb` 以外のファイルを指定した
- **対処**: 正しい拡張子の Access データベースファイルを指定してください

### `DAO.DBEngine が見つかりません`
- **原因**: Microsoft Access または Access Database Engine がインストールされていない
- **対処**: [Microsoft Access Database Engine 2016 再頒布可能コンポーネント](https://www.microsoft.com/ja-jp/download/details.aspx?id=54920) をインストールしてください。32bit / 64bit は Office と同じビット数を選択してください

### `ExtractToJSON.vbs が見つかりません`
- **原因**: VBS ファイルがバッチファイルと異なるフォルダにある
- **対処**: 3 ファイルをすべて同じフォルダに配置してください

### `viewer.html が見つかりません`（警告）
- **原因**: `viewer.html` がバッチファイルと異なるフォルダにある
- **補足**: 警告であり致命的エラーではありません。テキスト出力（`_クエリ一覧.txt`）は生成されます
- **対処**: 3 ファイルをすべて同じフォルダに配置してください

### データベースが開けない
- **原因候補**: パスワード保護されているデータベース（現バージョン非対応）・ファイル破損・他のアプリで排他ロック中
- **対処**: Access で正常に開けるか確認してから再実行してください

### ブラウザが自動で開かない
- **対処**: `viewer.html` を手動でブラウザで開き、生成された `_result.json` をドラッグ & ドロップして読み込んでください

### SQL ハイライトが効かない / フォントが崩れる
- **原因**: インターネット未接続のため CDN リソース（Highlight.js / Google Fonts）が読み込めない
- **補足**: 基本的な表示・検索機能は引き続き動作します

---

## 制限事項

- **Windows 専用**: バッチファイル・VBScript・DAO に依存しており、macOS / Linux では動作しません
- **パスワード保護 DB 非対応**: パスワードで保護されたデータベースは開けません
- **読み取り専用**: データベースのデータは読み取るのみで、変更・削除は行いません
- **出力先固定**: 出力ファイルは常に `AccessQueryExporter.bat` と同じフォルダに生成されます
- **システムオブジェクト除外**: `MSys` で始まるテーブルおよび `~` で始まるクエリは自動的に除外されます

## 技術情報

### ファイル構成

| ファイル | 技術 | 役割 |
|---------|------|------|
| `AccessQueryExporter.bat` | Windows Batch / PowerShell | エントリーポイント・ファイルダイアログ・起動制御 |
| `ExtractToJSON.vbs` | VBScript / DAO / ADODB.Stream | DB 読み取り・JSON/TXT 出力（UTF-8） |
| `viewer.html` | Vanilla HTML/CSS/JavaScript | インタラクティブビューア（SPA・外部依存なし） |

DAOは `DAO.DBEngine.120`（Office 2016+）を優先し、失敗した場合は `DAO.DBEngine.36`（Office 97-2003）にフォールバックします。

### JSON スキーマ（`_result.json`）

```json
{
  "filename": "database.accdb",
  "exported_at": "2026/02/27 12:00:00",
  "tables": [
    { "name": "テーブル名", "fields": ["フィールド1", "フィールド2"] }
  ],
  "relationships": [
    {
      "table": "親テーブル",
      "foreign_table": "子テーブル",
      "fields": [{ "from_field": "ID", "to_field": "親ID" }]
    }
  ],
  "queries": [
    { "name": "クエリ名", "sql": "SELECT ...", "type": "選択" }
  ]
}
```

### クエリ種別

| 種別 | 説明 |
|------|------|
| 選択 | SELECT クエリ |
| クロス集計 | TRANSFORM / PIVOT クエリ |
| 削除 | DELETE クエリ |
| 更新 | UPDATE クエリ |
| 追加 | INSERT INTO クエリ |
| テーブル作成 | SELECT INTO クエリ |
| データ定義 | CREATE / ALTER クエリ |
| パススルー | パススルークエリ |
| ユニオン | UNION クエリ |
| その他 | 上記以外 |
